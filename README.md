# myApp

This project contains a modern Next.js + Tailwind AI Studio for model building, chat, training controls, datasets, tutorials, community, and dahl.global connector support.

## Getting started

1. Install dependencies:
   npm install
2. Copy env file:
   cp .env.example .env.local
3. Add your OpenAI API key to `.env.local` if you want real AI chat replies.
4. Start development server:
   npm run dev

## Features

- Interactive chat interface
- Model tuning controls
- Dataset explorer
- Community panel
- Learning tutorials
- dahl.global connector integration
- Demo fallback when no API key is configured
